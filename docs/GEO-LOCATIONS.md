# Where Are We? — fixed location drops

The `countries` category now uses five real photographs instead of map silhouettes. Each tile drops the players into one static position: no walking, no panorama controls. All five answers require only the country. Category and clue IDs (`countries`, `geo-100`…`geo-500`) remain stable.

These are five curated drops, not a random global Street View service. A new game currently uses the same five scenes. All files are served locally; gameplay needs no image service or API key.

The question and image alt text do not disclose the city or country. Credits, source titles, locations and visible-clue explanations appear in the answer reveal and the separate [public photo credits](../game/location-credits.html) page. Hosts should open the credits after play because they contain answers.

Difficulty increases from a recognisable canal scene to ordinary street architecture. The 500-point clue gives South America as a continent hint; it would be overly broad without it. Photographic clues support a guess, not a logically unique proof. Rehearse the round with the intended guests before the party if values need adjusting.

All five originals were inspected before use. No visible watermarks or national flags were identified. Images retain their complete composition; only conventional resizing/re-encoding and metadata removal were applied. Share-alike images remain under their original CC BY-SA licence.
